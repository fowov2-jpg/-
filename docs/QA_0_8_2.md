# Управдом 0.8.2-alpha — проверка исходной сборки

Дата: 24 октября 2026. Основа: `feature/upravdom-0-8-2-sync`, коммит `1a45150`.
Это проверенная техническая альфа, не законченная коммерческая игра.
Предыдущий отчёт из импортированного архива сохранён в [QA_0_8_2_IMPORTED.md](QA_0_8_2_IMPORTED.md); его утверждения о перепакованном APK и отсутствующем доступе к GitHub относятся к прежней среде.

## Найденные и исправленные проблемы

- Импорт открывал подготовку независимо от фазы компании. Теперь активная смена открывается на паузе на карте, итог смены и завершение района открывают соответствующий диалог; подготовка открывает состав бригад.
- При невозможности сохранить импорт интерфейс уже заменял текущую компанию и показывал успех. Теперь сначала выполняются проверка и запись, затем замена состояния. Ошибка записи или неверный JSON оставляют действующую компанию и основной файл сохранения прежними.
- При импорте очищаются выбранная заявка, экипаж, очередь, страница адресов и доля игровой минуты, чтобы сведения предыдущей компании не попадали в новую.
- Уточнение обстоятельств во время осмотра теперь сокращает оставшееся время, однократно и с учётом уже прошедшего осмотра.
- Отклоняются противоречивые сохранения с активной сменой на 480-й минуте и отчётом до конца смены. Формат сохранения остаётся v6; ключи и миграции v4/v5 сохранены.
- Символы управления временем заменены векторными иконками, чтобы не зависеть от наличия глифов в системном шрифте.
- Обновление HUD сохраняет оформление счётчика заявок и подпись нижней панели.
- Версия приложения, Android versionName, User-Agent и названия артефактов CI обновлены до 0.8.2. Android versionCode увеличен с 8 до 9. В настройках видна `0.8.2-alpha`.
- Android-сценарий новой компании учитывает обязательный экран выбора района.
- В `npm run test:ui` включены отдельные проверки нового интерфейса и техники.

## Проверки

- `npm test`: 91 тест, все успешны. Добавлены проверки совпадения прогноза с настоящим выездом/осмотром/ремонтом, ранжирования, оперативной сводки, уточнения во время осмотра и противоречивой фазы сохранения.
- `CHROMIUM_PATH=/usr/bin/chromium node tools/operator-verify.cjs`: 6 сценариев, без ошибок JavaScript. Импорт активной смены с реальным назначением, импорт отчёта и следующий день, ошибка записи и неверный JSON без потери текущей компании, переход в следующий район и завершение кампании, ширины 360/412/1200. Артефакты: `test-results/operator/`.
- `npm run test:balance`: обе полные кампании завершили 19 980 заданий. Три экипажа: 1518 дней, минимум 3 000 000 ₽, просрочки 16,65%; шесть: 1015 дней, минимум 1 908 000 ₽, просрочки 6,73%. Автосимуляция доказывает проходимость при используемой стратегии, не качество баланса живой игры.
- `npm run test:fleet`: 14 сценариев покупки/комплектации/назначения/перезагрузки для иллюстрированного автопарка, четыре ширины экрана; отсутствующих ресурсов не обнаружено.
- `assembleDebug assembleRelease lintDebug lintRelease assembleDebugAndroidTest`: успешно с JDK 17, Gradle 8.9 и Android SDK 35. Получены настоящий debug APK и неподписанный release APK. Тестовый APK скомпилирован; инструментальные тесты на устройстве не запускались.
- У debug APK проверена подпись Android APK Signature Scheme v2; versionName `0.8.2-alpha`, versionCode `9`. Все 54 файла ресурсов внутри APK побайтово совпадают с `web/`.
- `tools/ui-smoke.cjs`: все пять разделов, четыре ширины, полная смена, резервная копия, экспорт и импорт; успешно.
- География: 20 районов, блокировки прогрессии, загрузка графики; успешно.
- Движение: 17 моделей, пять сценариев; успешно.
- Прежняя компания: 33 сценария экранов, персонала, склада, техники и завершения компании; успешно.

## Ограничения приёмки

Оригинальная графика кварталов и атлас техники сохранены. Новые 3D-модели, новое художественное депо и полная переработка карты не созданы. В фоновой графике остаются повторяющиеся кварталы и нарисованные автомобили.

Для окончательной приёмки нужны установка текущего APK на Android, проверка системного выбора файлов, паузы при сворачивании, системных отступов, жестов и производительности на реальном устройстве. Также нужны визуальная приёмка, длительная ручная игра, production-подпись и выбранный магазин. Автоматические браузерные проверки не подтверждают эти пункты.
