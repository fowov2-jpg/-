# Управдом 0.2.0-rc.1

Кандидат в релиз для проверки на Android. Не магазинный релиз и не подписанная production-сборка.

## Состав

- Детализированный локальный фон Северного района, созданный для проекта по пользовательскому референсу. Динамические маркеры, машины, адреса и маршруты рисуются отдельно.
- Пять разделов: карта, заявки, бригады, финансы, гараж.
- Шесть именованных специалистов в трёх бригадах. Опыт, обучение и усталость сохраняются на уровне бригады.
- Дорожный граф, кратчайшие маршруты и время поездки по длине пути. Машины начинают работу из гаража.
- Основное и резервное сохранения, восстановление, миграция версии 1 в 2, импорт/экспорт JSON.
- Импорт/экспорт на Android через системный выбор документа, без разрешения на всё хранилище и без JavaScript bridge.
- Звуковые сигналы обращений; настройки звука, анимации и адресов.
- Офлайн-игра без аккаунта, рекламы, покупок и сетевых разрешений.

## Автоматические ворота

`npm test`: модель, переходы смен, маршруты, миграции, резервирование, обработчики интерфейса и статический сервер.

`npm run test:ui`: Chromium, ширины 360/412/560/1200, все пять разделов, три назначения, движение и ремонт, пауза в карточке и в фоне, полный день и следующий день, восстановление, экспорт и импорт. Снимки экранов сохраняются в `test-results/screenshots/`.

GitHub Actions выполняет тесты, браузерную проверку, `assembleDebug assembleRelease lintDebug lintRelease`. Артефакты:

- `upravdom-0.2.0-rc.1-debug-apk` — устанавливаемая тестовая сборка с debug-подписью.
- `upravdom-0.2.0-rc.1-unsigned-release` — неподписанная release-сборка, не предназначена для установки.
- `upravdom-browser-evidence` — снимки экранов и тестовый экспорт.

## Ручная проверка на устройстве

- [ ] Android 8+ с WebView/Chromium 100+ и актуальный Android: установка и запуск.
- [ ] 360/412 dp, крупный системный шрифт, жестовая и кнопочная навигация, вырезы экрана.
- [ ] Pan, pinch, выбор маркера и дома; после pinch не открывается случайная карточка.
- [ ] Три назначения, смена этапов, возврат свободного статуса и следующий день.
- [ ] Пауза при сворачивании, системный Back, перезапуск процесса с сохранением прогресса.
- [ ] Экспорт JSON в выбранную папку, отмена выбора, импорт через системный picker, восстановление прогресса.
- [ ] TalkBack, контраст, экономия батареи и отсутствие перегрева за 30 минут игры.
- [ ] Отказ в доступе к хранилищу и нехватка места: сообщение об ошибке без удаления прежних данных.
