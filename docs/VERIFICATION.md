# Проверка версии 0.1.0

Дата: 21 октября 2026.

## Выполнено

- `node --test tests/*.test.js`: **12/12 успешно**.
- Проверены точные стартовые условия и каталог из 20 заявок.
- Проверены запрет неверной специализации и повторного назначения, отсутствие списания при отказе.
- Проверены полный выезд/ремонт, подрядчик, однократный ущерб за просрочку.
- Проверены сохранение/загрузка с детерминированным продолжением, переход смены и сохранение незаконченного ремонта.
- Симуляция десяти смен с автоматическим распределением: финансовый отчёт сходится с журналом, назначения не теряют заявки.
- Синтаксис app.js и map.js проверен Node.js.
- Canvas-карта отрисована через @napi-rs/canvas; результат просмотрен, обнаруженное наложение площадки на здание исправлено.

## Не выполнено / ограничения среды

- Браузерный UI smoke test подготовлен, но не запущен успешно: Chromium отсутствует, загрузчик возвращает повреждённый архив. Нельзя считать проверенными реальные касания, pinch, адаптивную вёрстку и browser localStorage end-to-end.
- Android assembleDebug и lintDebug не запускались: Android SDK и Gradle отсутствуют. Workflow подготовлен, но до загрузки в репозиторий и успешного завершения Actions факт сборки APK не подтверждён.
- Нет проверки на эмуляторе или физическом Android, тестов производительности и TalkBack.
- Целевой GitHub-репозиторий: https://github.com/fowov2-jpg/- . Статус сборки уточняется по GitHub Actions.

## Обязательная проверка перед передачей APK игрокам

1. Успешный workflow Tests + Android; скачать debug APK из artifacts.
2. Установка на Android 8+ и актуальный Android; 360 dp и 412 dp, жестовая/кнопочная навигация.
3. Назначить заявку и убедиться, что движение и этапы завершаются.
4. Свернуть приложение на минуту и вернуться: время не должно уйти вперёд.
5. Закрыть процесс и запустить заново: деньги, заявки и экипажи сохранены.
6. Пройти смену до отчёта, перейти на новый день, проверить продолжение активной работы.
7. Проверить два пальца, масштаб, панорамирование, все четыре вкладки и системную кнопку Back.
8. Проверить недостаток денег, занятые бригады, низкое топливо, обучение и предупреждение при новой игре.
