# Конфиденциальность — Управдом

Дата вступления в силу: 24 октября 2026 года.

«Управдом» работает на устройстве без регистрации, подключения к серверу, рекламы, аналитики и встроенных платежей. Приложение не собирает и не передаёт разработчику персональные данные, идентификаторы устройства, местоположение, историю игры или содержимое файлов.

## Прогресс и настройки

Прогресс компании и настройки хранятся локально в закрытых данных приложения. Они не синхронизируются между устройствами. В приложении отключено автоматическое резервное копирование средствами Android. Удаление приложения или очистка его данных удаляют локальные сохранения.

## Импорт и экспорт

Только по команде игрока приложение открывает системный выбор файла. При импорте оно читает выбранный документ JSON. При экспорте оно записывает компанию в выбранный игроком файл. Приложение не запрашивает доступ ко всему хранилищу. Если игрок выбирает облачное хранилище через системный проводник, передача выполняется выбранным провайдером по его правилам, а не сервером игры.

## Сторонние сервисы

В игре нет SDK рекламы, аналитики или внешней авторизации. Для отображения локального интерфейса используется Android System WebView. Приложение не запрашивает разрешение INTERNET.

## Удаление данных

Локальные данные удаляются через системные настройки Android: «Приложения → Управдом → Хранилище → Очистить данные», либо при удалении приложения. Экспортированные игроком файлы удаляются отдельно средствами выбранного хранилища.

## Вопросы

Контакт издателя указан в карточке приложения выбранного магазина.
