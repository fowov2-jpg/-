# Архитектура 0.3.0-alpha

## Симуляция

`engine.js` — детерминированное ядро без UI и реального времени. Схема 3 хранит сотрудников, автомобили, бригады как назначения двух людей и машины, дома с договорами и доверием, склад, поставки, заявки, кампанию, журнал и отчёт. Каталоги — `content.js`. Старые схемы 1 и 2 проверяются `legacy-engine.js` и мигрируют при загрузке.

Смена: prep → active → report → prep. Найм, состав бригад, техника и договоры меняются перед сменой. Заявка: new → travel → diagnosis → repair → done; возможен contractor. Связанные аварии используют blocked и ссылку на предыдущий этап. Работы продолжаются на следующий день с сохранением остатка времени.

Выезд проверяет специализацию, занятость, топливо, состояние, усталость, запас комплектов и вместимость машины. Комплекты резервируются один раз. Рабочие параметры бригады выводятся из сотрудников и автомобиля. Выплаты и доверие рассчитываются по каждому дому. Отрицательный бюджет, нулевая репутация или потеря всех договоров заканчивают кампанию.

## Представление

ES modules, CSS, Three.js r174 (локально, MIT). `management.js` строит страницы кадров, автопарка, склада, договоров и финансов. `app.js` обрабатывает команды, диалоги, навигацию и время.

`map.js` создаёт отдельные здания с процедурными фасадами, крыши, деревья, дворы, дороги и машины. WebGL 2; при его отсутствии упрощённая Canvas 2D карта. Ортографическая камера поддерживает масштаб, перемещение, поворот, наклон и переход между районами. Адреса — HTML-кнопки, здания выбираются лучом камеры. `roads.js` задаёт граф города 1000×1650; кратчайший путь определяет и геометрию движения, и время поездки.

Карта ограничена 20 кадрами в секунду и DPR 1.5. Анимация прекращается при паузе, открытом диалоге, скрытой вкладке или отключённом движении. Симуляция использует целые игровые минуты; движение между ними интерполируется отдельно.

## Сохранение

Ключи localStorage остаются `upravdom.v1` и `upravdom.backup.v1`; версия схемы внутри JSON — 3. Валидируются ресурсы, взаимные ссылки назначений, склад, поставки, договоры и отчёт. Перед записью валидируется новое состояние; предыдущая корректная запись становится резервной. Повреждение обеих копий блокирует автосохранение до явного сброса или импорта. Навигация не затирает повреждённые данные.

Настройки хранятся отдельно. Импорт с подтверждением и экспорт JSON доступны в настройках. Фоновое время не начисляется. Журнал хранит 500 операций. `opening` фиксируется перед подготовкой: дневной результат включает закупки и развитие до запуска смены.

## Android

Java 17 Activity, WebViewAssetLoader, локальный https://appassets.androidplatform.net. Сетевых разрешений нет; file/content access и mixed content запрещены, неизвестные запросы отклоняются. Импорт — ACTION_OPEN_DOCUMENT, экспорт — ACTION_CREATE_DOCUMENT. JavaScript bridge отсутствует. Экспорт допускается только из доверенного главного фрейма. Используются те же `web/` исходники.

Сворачивание отправляет upravdom-pause. Back закрывает карточку либо сворачивает приложение. Проверка жестов, lifecycle и производительности 3D на устройстве ещё необходима.

## Проверки

`npm test` — ядро, экономические ограничения, состав команды, материалы, миграции, дороги, сохранение и обработчики UI. `npm run test:ui` — Chromium: создание бригады, покупка автомобиля, договор, закупка, смена, пять разделов, четыре ширины и восстановление данных. CI выполняет также assembleDebug, assembleRelease, lintDebug и lintRelease. Успешная сборка не заменяет тестирование на Android.
