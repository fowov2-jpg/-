# Архитектура

## Модель

Состояние версии 1: день, минута, phase, бюджет, репутация, PRNG seed, дома, бригады, обращения, журнал, отчёт. Детерминированное ядро `engine.js` не зависит от UI и реального времени. Каждая команда проверяет допустимость перед изменением денег и назначения. Однопоточный tick обновляет симуляцию по целым игровым минутам.

Состояния смены: prep → active → report → prep. Состояния заявки: new → travel → diagnosis → repair → done; альтернативно new → contractor → done. Бригада освобождается только после завершения. В конце смены активные назначения не удаляются.

## Представление

Vanilla JS ES modules, CSS и Canvas 2D. Рендер карты отделён от DOM интерфейса. Изометрическая проекция: screenX=500+49×(x−y), screenY=100+27×(x+y)−height. Дороги — сетка линий 0/4/8. Машины проходят маршрут по ортогональным сегментам через дорогу x=4. Время поездки пока приближённое; граф дорог с весами и Dijkstra запланирован на 0.3.

Игра обновляется раз в секунду. Ввод pan/pinch не меняет состояние симуляции. Экран перечитывает состояние после команд и tick; для большой карты потребуется dirty rendering и анимация requestAnimationFrame с интерполяцией.

## Сохранение

localStorage `upravdom.v1`; JSON с версией. Запись после команд и каждого tick. Загрузка проверяет числовые поля, дома, бригады, заявки, взаимные ссылки назначений, журнал и отчёт. При повреждённом сохранении или недоступном хранилище показывается предупреждение, автосохранение блокируется до явного подтверждения новой компании: прежние данные не затираются при навигации или выходе. Для production добавить миграции, резервную копию, контроль целостности и экспорт/импорт. Фоновое время не начисляется.

Бюджет `opening` фиксируется перед подготовкой каждого дня. Результат смены включает профилактику, ТО, оснащение и обучение до запуска смены, а также все операции во время работы.

## Android

Activity на Java 17, WebViewAssetLoader отдаёт только упакованные assets через https://appassets.androidplatform.net. File/content access отключены, mixed content запрещён, сетевого разрешения нет, неизвестные запросы отклоняются. JS bridge не используется. Браузерный и Android-режимы используют одни исходники `web/`, копирование на этапе сборки не нужно.

Пауза Activity отправляет событие upravdom-pause и сохраняет игру. Android Back закрывает карточку или сворачивает приложение. Системные отступы обрабатываются нативно. Проверка жестовой навигации и lifecycle на устройстве обязательна до релиза.

Документация подхода: https://developer.android.com/develop/ui/views/layout/webapps/load-local-content

## Сборка и тесты

`npm test` не устанавливает пакеты и запускает встроенный node:test. GitHub Actions: unit tests → Gradle assembleDebug и lintDebug → APK artifact. Android SDK/Gradle локально в среде автора не установлены; готовность CI не равна факту успешной Android-сборки. Release signing, AAB и публикация отдельно.

## Развитие без переписывания ядра

1. Перевести контент TYPES в JSON со схемой и локализуемыми строками.
2. Добавить сущности Employee, Vehicle, Inventory и Contract, сохранить Crew как назначение людей и машины.
3. Ввести явные команды и события для повторов и debugging.
4. Заменить сеточный маршрут графом дорог, добавить закрытия и пробки.
5. Миграции сохранений до каждого изменения схемы.
6. Сервис тендеров и конкуренты используют те же команды экономики; отдельного backend пока не требуется.
