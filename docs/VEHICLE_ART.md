# Машины по пользовательским референсам

Архив `Download.zip`, переданный 24 октября 2026, содержит 14 фотографий техники, а не исходный код игры. Подключены все 14 вариантов, чтобы не исключать пользовательские референсы без основания. Вместе с прежними тремя моделями в каталоге теперь 17.

- `docs/vehicle-references/contact-sheet.jpg` — обзор исходных фотографий.
- `assets/vehicles/fleet-topdown-draft.png` — созданный прозрачный лист 2D-изображений, вид сверху, передняя часть направлена вверх.
- `assets/vehicles/manifest.json` — соответствие ячеек фотографиям, предварительные названия моделей, статус набора.
- `web/assets/fleet-reference.png` — общий игровой атлас.
- `web/fleet-art.js` — измеренные прямоугольники изображений и относительная длина машин на карте.

## Подключение

Гараж и Canvas берут каждый автомобиль по измеренному прямоугольнику из исходного PNG. Исходное изображение не перекодировано и не обрезано: CSS и Canvas выделяют нужную область при отображении. Перед машин направлен вверх; Canvas поворачивает изображение по направлению дорожного сегмента вокруг его центра. Длина тяжёлых машин на карте больше длины фургонов.

Работают покупка, сборка бригады, назначение, движение, ремонт, обслуживание, продажа и восстановление сохранения. Идентификаторы прежних трёх моделей и версия схемы сохранений сохранены. Каталог из 17 моделей не меняет лимит автопарка: 12 машин одновременно. Кнопки покупки отключаются при заполненном гараже.

Спецтехника имеет ограниченный список работ, показанный в карточке покупки. Краны подходят для труб, насосов, кровли и ступеней; самосвалы — для обледенения входа и ступеней; подъёмники — для светильников, кровли, окон и водостоков. Неподходящее назначение не расходует материалы, топливо или деньги. Обычные пять машин из референсов обслуживают все профили. Это предварительная привязка к существующим заявкам, не самостоятельная симуляция грузоподъёмных операций.

## Ограничения

- Это 2D-спрайты, не 3D-модели. Генерация приблизительно передаёт фотографии; пропорции отдельных кабин и кузовов, особенно УАЗа, требуют художественной доработки. Точные заводские модификации не подтверждены.
- В 0.5 добавлены процедурные 2D-анимации стрел, корзин, ножничного подъёмника и кузова; см. [MOTION_BALANCE_0_5.md](MOTION_BALANCE_0_5.md). Физики груза, ручной гидравлики и отдельной профессии машиниста пока нет.
- Цены, скорость, вместимость и содержание — предварительные игровые параметры. Ограничение назначения действует с учётом специализации бригады; техника не заменяет персонал.
- На этапе добавления машин отсутствовал файл фона. В версии 0.4 пользователь предоставил исходные жилой и промышленный тайлы: они включены в `web/assets/districts/`, а новая карта описана в [CAMPAIGN_0_4.md](CAMPAIGN_0_4.md). APK локально не собирался.

## Проверки

- `npm test`: 67 тестов, включая полный цикл покупки, восстановления, назначения, выполнения, продажи каждой новой модели, ограничения спецтехники и лимит гаража. Матрица всех типов заявок и домов расширена на весь каталог.
- `CHROMIUM_PATH=/usr/bin/chromium npm run test:fleet`: 14 цепочек покупки → сборки бригады → назначения → перезагрузки → Canvas и каталог на ширинах 360, 412, 560, 1200. Известный отсутствующий файл карты фиксируется отдельно; другие HTTP-ошибки и ошибки JavaScript приводят к провалу проверки.
- Снимки и отчёт: `test-results/fleet/`. Это проверка машин, не приёмка фона карты или Android.
