# Управдом 0.8.2-alpha — техническая сдача изменений

**Статус:** тестовое инкрементальное обновление; визуальная приёмка проекта НЕ пройдена.

Основа: 0.8.1-alpha (с игровым рендерером и механикой 0.6.0-alpha из `feature/city-geography-rebuild`). Ни одного нового случайного изображения кварталов или машины не добавлено. Техника берётся из существующего `fleet-reference.png`; полноценные 3D-ассеты НЕ созданы.

## Исправлено сейчас

1. На карте введены указатели к новым авариям вне области просмотра. Указатели используют существующие ID настоящих заявок, окраску службы и собственные векторные пиктограммы. Нажатие открывает заявку; совместимо с диспетчеризацией «машина → происшествие». В `canvas.dataset.edgeCalls` доступно количество таких заявок для проверки.
2. Масштаб спрайтов игровых машин ограничен 18–36 CSS-пикселями для уменьшения несоразмерности с жилыми кварталами. Сами исходные машины и маршруты не изменены.
3. Приведены к единой более компактной визуальной системе меню, подготовка, табы, карточки, HUD, модальные панели и нижний док. Новое оформление — файл `web/game-polish.css`, без замены оригинального городского арта.
4. В бригадах и гараже вместо длинной текстовой строки добавлены индикаторы топлива и технического состояния, значения берутся из актуального состояния игрового движка.
5. Сохранены работающие функции 0.8.1: маршрутизация, выезд, ремонт, возврат к индивидуальной стоянке, блокировка повторного назначения, сохранения v6.

## Выполненные проверки

- `npm test`: три комплексных набора (логика диспетчеризации, 20×999, парковочные позиции, ремонт и возврат, сохранение).
- `python tools/qa_mobile.py`: Chromium, портрет 344×689; отсутствие JS-ошибок, пять экранов, проверка высоты карточек/гаража, наличие указателей, выбор бригады, выезд, возврат. Лог: `qa/mobile-final2.log`.
- `python tools/qa_offline.py`: Chromium 412×915 и 360×800: запуск/смена/картa/заявки/назначение и двухкликовый маршрут. Консольный лог `qa/offline.log` показывает успешные сценарии; процесс был прерван по ограничению времени после вывода результатов, поэтому этот прогон не считаем полностью завершённым.
- APK перепакован на основе предыдущего подписываемого Android-ресурса 0.6; архив не повреждён; подпись Android APK Signature Scheme v2 проверена локально (`apk-verification.json`). В APK побайтово сверены шесть изменённых/основных файлов.

## Не выполнено — критически важно

- **НЕТ полного набора профессиональных 3D-моделей 17 автомобилей**. Атлас техники остаётся прежним, визуально недостаточным для коммерческого качества.
- **НЕТ нового художественного депо с физическими парковочными площадками.** Использованы существующие придорожные позиции; запрещённые фальшивые прямоугольники не возвращались.
- **НЕТ полной художественной переработки всех пяти экранов до уровня современной коммерческой игры**. Это технически и визуально улучшенная альфа-версия, но не завершённый редизайн.
- Существующая карта содержит повторяющиеся кварталы и неподвижные автомобили непосредственно в рисунках.
- **Не выполнялся запуск на физическом Android и отсутствует подтверждённая проверка APK в эмуляторе Android текущей сборки.** Только браузерный Chromium и структурная/криптографическая проверка APK.
- **GitHub не изменён.** Интернет-доступ для `git` недоступен; локальный ZIP содержит веб-исходники и инструменты, но не оригинальный Android Gradle-проект. Нативная часть остаётся в репозитории GitHub.
- Тестовая подпись может отличаться от предыдущих APK; перед переустановкой необходимо экспортировать сохранение.

Версия **НЕ ПРИНЯТА как финальная** и не должна называться законченной игрой.
