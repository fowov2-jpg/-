# Дорожный граф и погода — техническая документация 0.3

Статус: экспериментальная механика в ветке `feature/roads-weather-2026-10-30`, зависимость от PR #19. Не означает, что Android-релиз готов.

## Источник истины

- `web/routing.js` реализует локальную модель дороги и погоды без DOM, таймеров и случайных внешних данных.
- `routePlan(from,to,{day,minute,blockedEdges})` возвращает `points` (массив координат дороги), `distance`, `weightedDistance`, `minutes`, `weather`, `rush`.
- `engine.dispatch` рассчитывает маршрут перед списанием денег. После успешного назначения он сохраняет `crew.route` и `crew.total/remaining`. При завершении работы маршрут удаляется.
- `web/map.js` **не строит второй маршрут**: показывает `crew.route` и перемещение по той же геометрии. Старые версии сохранений без `route` поддерживаются — для них карта рассчитывает запасной визуальный путь, не изменяя игровое ETA.
- `crewOption` использует `travelMinutes` из ядра с текущим днём/временем; показанная оценка соответствует фактическому выезду, если между просмотром и нажатием не изменилась смена.

## Геометрия первой игровой карты

Проезжие улицы находятся на линиях `x ∈ {0,4,8}` и `y ∈ {0,4,8}`. Перекрёстки — 9 точек пересечения; ещё 3 точки — остановки у домов: `[2,4]`, `[6,4]`, `[2,8]`. Дороги только ортогональные. Связи между двумя точками считаются дорожными исключительно при совпадении разрешённой координаты оси; остановки нельзя напрямую соединять по вертикали `x=2`, поскольку там нет улицы.

Алгоритм: Dijkstra по взвешенным дорожным рёбрам. Веса — расстояние вдоль улицы × погодное замедление × дополнительная утренняя/вечерняя загруженность центральных участков. Выбор маршрута детерминирован при одинаковых входных параметрах. Время выезда включает базовые 10 игровых минут плюс округлённый вверх взвешенный путь. Это игровые единицы и баланс, а не настоящие ETA по городским дорогам.

Границы пробок: первые 90 игровых минут смены, а также последние 60. Сезоны сменяются раз в 7 игровых дней. Внутрисезонные погодные варианты детерминированы номером дня. Снег, дождь и мороз влияют на движение; снег/мороз добавляют веса зимним происшествиям, дождь — протечкам кровли и проблемам водостока. Влияние на ремонтные работы и риск отдельных инженерных систем пока **не реализовано**.

## Развитие

Для следующего этапа:
1. Добавить игровую сущность перекрытия дороги и пересчёт пути **до** назначения и во время поездки; нынешний `blockedEdges` доступен как параметр API и в тестах, но не редактируется игроком.
2. Довести дороги до нескольких кварталов и независимых депо; связать маршруты с масштабируемой геометрией.
3. Ввести состояние отдельных инженерных сетей домов, чтобы погода влияла не только на выбор каталога происшествий.
4. Для анимации можно использовать `requestAnimationFrame` с интерполяцией, оставив игровую симуляцию на целых минутах.
5. Измерить FPS/память на Android 8 и современной версии Android, а также проверить работу жестов.

## Обязательные проверки

`npm test` включает старые симуляционные тесты и тесты графа: доступность всех трёх домов, правильные дорожные оси, повышенную ETA в снег и пробку, обход перекрытий, отсутствие пути при изоляции остановки, единый маршрут UI/ядра, сериализацию маршрута и загрузку старого v1-сохранения. GitHub CI дополнительно запускает `assembleDebug` и `lintDebug`. Это **не** замена установки на телефон.
