# Репозиторий проекта

Проект размещается в https://github.com/fowov2-jpg/- , ветка `main`.

После загрузки откройте Actions → Test and build Android. Успешная Android-задача публикует debug APK в артефактах запуска. Release-подпись и публикация в Google Play в эту конфигурацию не входят.

Локальный запуск и требования сборки описаны в README.md. Не добавляйте пароли, токены и ключи подписи в репозиторий.
