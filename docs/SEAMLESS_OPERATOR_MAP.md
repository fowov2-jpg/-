# Бесшовная карта редактора — рабочая ветка

Обновление 24.10.2026: актуальная кампания 0.4 с 20×999 описана в [CAMPAIGN_0_4.md](CAMPAIGN_0_4.md). Пользовательские тайлы получены и включены в `web/assets/districts/`; ниже сохранена история прежней версии.

Основа: исходная версия 0.3.2-alpha + исправленное управление жестами. Ветка `feature/seamless-operator-map` содержит **код карты**, но **пока не содержит обязательный бинарный ресурс** `web/assets/seamless-neighborhood.webp`. Полноразмерный WebP включён в переданный пользователю ZIP исходников; загрузить его отдельно в GitHub ещё необходимо. **Не собирать и не сливать ветку как законченный релиз без этого файла.**

## Сделано

- Бесшовная сетка 8×8, 64 одинаковых квартала размером 1536×1024 каждый, без зеркалирования.
- Canvas рисует только части сетки, видимые камерой. Граница перемещения — все четыре направления, масштабирование пальцами через `transformCamera`.
- `city-grid.js` генерирует 999 *координатных мест* зданий на каждый район, с постоянными id по seed.
- `roads.js` содержит новую геометрию дорог и существующие 12 игровых точек (по четыре на район); дороги соединены в рамках исходного квартала каждого района.
- `content.js` сопоставляет действующие договоры с новыми объектами на изображении.
- Автомобили получают вид сверху, чтобы соответствовать новой перспективе.
- Тесты `tests/seamless-city.test.js`, `tests/map.test.js`, `tests/roads.test.js`.

## Чего пока нет

- Файл `web/assets/seamless-neighborhood.webp` ещё нужно добавить в репозиторий. Он готов и включён в архив полного проекта, переданный в чате.
- Договоры, заявки и автомобили на остальных 987 зданиях ещё не интегрированы; карта не должна показывать фальшивые метки или интерактивные несуществующие договора.
- На соседних 64 плитках пока повторяется **одна и та же** картинка от пользователя. Для разнообразных домов понадобятся другие совместимые тайлы. Нет настоящего сетевого графа всех 64 кварталов.
- Не пройдены полный браузерный UI / Android-эмулятор для этого изменения. Сборку APK и релиз не выпускать без CI и проверки ассета.
