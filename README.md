# Управдом · диспетчерская ЖКХ

**0.9.0-rc.1 — области и мобильная диспетчерская по референсу владельца.** Новая компания начинает с трёх домов, трёх экипажей и 3 млн ₽. В первой смене три обращения, одно одновременно. Затем поток растёт до 6–10 обращений за смену; новое событие ждёт свободную подходящую службу. Норматив начинается при фактическом поступлении, после 14:10 новые обращения не поступают.

В каждой из 20 областей 999 адресов, разделённых на районы по 60 домов и последний на 39. Район развивается от трёх договоров, ещё три места открываются каждые 20 его баллов. Первый дополнительный район стоит 80 баллов и 90 000 ₽; следующая область — от 300 баллов после трёх районов и шести смен. Между сменами можно вернуться в любую открытую область и район. Прежние договоры обслуживают диспетчеры; помощник после 60 баллов настраивается в «Бригады → Диспетчеры».

Сохранены подробный осенний город и 17 Blender-моделей. На карте компактная верхняя сводка, поиск бригад слева, карточки техники и пять кнопок снизу. В «План» находятся районы, договоры и цели. Добавлены четыре сценария, разовые награды и постепенное открытие спецтехники. Состав и машину бригады можно менять без её удаления. Исходники графики: [art/blender/README.md](art/blender/README.md).

Текущие правила, экономика, совместимость и ограничения: [docs/REGIONS_0_9.md](docs/REGIONS_0_9.md). История сравнения с мобильной 112 и прежних правил: [docs/PROGRESSION.md](docs/PROGRESSION.md). Это кандидат для прохождения владельцем; магазинная публикация не выполнялась.

## Запуск

Node.js 20+, пакеты для самой игры не нужны:

```sh
npm test
npm start
```

Открыть http://localhost:4173 → «Новая игра» → проверить службы → «Начать смену». Обращение открывается на паузе. Во вкладке «Разговор» уточните обстоятельства и примите решение; во вкладке «Работы» сравните подходящие экипажи и назначьте службы. Затем продолжите время. Смена 08:00–16:00; одна реальная секунда соответствует игровой минуте, доступны 1×/2×/4×.

Бригады можно выбирать также на карте или в нижней панели, затем нажимать на аварию. Ждущую другие службы бригаду можно отозвать. В меню, при сворачивании и после повторного запуска время остановлено. Игра полностью локальная, без аккаунта и сервера.

## Сохранения

Новые компании используют схему v9. Компании v7/v8 переходят к областям и районам с сохранением текущих работ и отдельным исходным архивом. Незавершённые этапы, маршруты, назначения, решения, отключения и состояние домов сохраняются между запусками и сменами. Сохранения v4–v6 по-прежнему читаются и продолжаются по прежним правилам. При замене такой компании новой сохраняется отдельный исходный архив, доступный в настройках для экспорта; переходящие работы не переосмысливаются автоматически.

Самая ранняя компания хранится отдельно и доступна в настройках либо через `?legacy=1`. Параметр `?classic=1` нужен разработчикам для регрессионной проверки создания v6-компании. Основной запуск создаёт v9.

Экспортируйте компанию перед очисткой данных или переустановкой. Автосохранение и резервная копия находятся в данных приложения; удаление приложения может удалить их.

## Android

JDK 17, Gradle 8.11.1, Android SDK 36, AGP 8.10.1; минимум Android 8.0 / API 26 с обновлённым WebView / Chromium 100+.

```sh
gradle -p android assembleDebug assembleRelease bundleRelease lintDebug lintRelease
```

GitHub Actions собирает устанавливаемый debug APK и неподписанные магазинные APK/AAB. Артефакт: `upravdom-0.9.0-rc.1-debug-apk`. Импорт и экспорт используют системный выбор документа; сетевые разрешения, реклама и платежи отсутствуют. Инструкция по подписи: [docs/RELEASE.md](docs/RELEASE.md). Публикация в магазине сейчас не выполняется.

## Проверка

```sh
npm install --no-save --package-lock=false playwright@1.62.1
npx playwright install chromium
npm run test:dispatch
npm run test:progression
npm run test:ui
npm run test:balance
npm run test:performance
```

`test:dispatch` проходит первую смену через реальные элементы интерфейса, проверяет продолжение компании и сохранение связанной аварии на 344/412/960 пикселях. `test:progression` проходит три смены через интерфейс, включает помощника, восстанавливает его выезд после перезапуска и открывает второй район за баллы. `test:ui` также проверяет совместимость предыдущих компаний. Отчёты и снимки находятся в `test-results/`. `test:balance` проверяет обе модели кампании, включая четыре стратегии новой кампании; это боты, а не оценка интереса или сложности для человека. Можно указать `CHROMIUM_PATH` для установленного системного Chromium.

## Основные модули

- `web/campaign-engine.js` — общая компания, управление ресурсами и транзакционное сохранение v4–v9.
- `web/career-progression.js` — квоты смены, экономика и помощники; `territory-progression.js` — области, районы, цели и возврат управления.
- `web/shift-operations.js` — этапы аварий, несколько служб, зависимости, последствия, дома и рост компании.
- `web/operations-content.js` — авторские обращения, решения, оснащение, погода и планы смен.
- `web/campaign-map.js` — общий художественный рендерер для старой и новой кампании; `web/operations-ui.js`, `web/operations-ui.css` расширяют существующие компоненты для совместных аварий и домов.
- `web/campaign-app.js` — жизненный цикл приложения, управление временем, ввод, диалоги и импорт/экспорт.
- `web/campaign-city.js`, `web/city-layout.js`, `web/city-geography.js` — адреса и координаты города; исходная художественная карта используется в обеих кампаниях.
- `android/` — офлайн WebView и системная работа с документами.

В игре используются оригинальные материалы проекта. Графика, звук, тексты и код 112 Operator не копируются. Открытая лицензия не назначена; её выбирает владелец перед распространением.
