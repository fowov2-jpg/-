# Управдом · диспетчерская ЖКХ

**0.8.2-gameplay.2 — переработка игрового процесса после сравнения с мобильной 112 Operator.** Новая компания начинает с 3 млн ₽, трёх домов, трёх автомобилей и шести сотрудников. Игрок принимает обращения, выбирает способ локализации и координирует несколько служб на одной аварии.

Первая смена поставлена вручную: спокойное обращение, протечка, затопление подвала, обычная нагрузка и отчёт с последствиями. В затоплении электрики снимают напряжение, сантехники перекрывают ввод, ремонтники откачивают воду; ремонт трубы и восстановление питания зависят от завершения предыдущих этапов. У задержки появляются дополнительные работы и ущерб. Общее перекрытие затрагивает соседние дома, доверие и перерасчёт платы.

Исходная графика города, меню, выбор района и карточки экипажей сохранены. В этот интерфейс встроены выбор оснащения, девять сценариев с разговорами, погода и заторы, состояние и история домов, договоры и профилактика. Обучение и финансы работают в основной кампании. Рост компании зависит от результатов, доверия и договоров. Обязательный перебор 999 заданий для новой компании убран. Подробности и ограничения: [docs/DISPATCH_GAMEPLAY.md](docs/DISPATCH_GAMEPLAY.md).

Визуальное направление предыдущей сборки `0.8.2-gameplay.1` отклонено владельцем: восстановлены исходные кварталы, техника и оформление. Это сборка для игровой приёмки. Прежняя сборка не была принята владельцем; новая версия не объявляется магазинным релизом по результатам автоматических тестов. Исходный разбор: [сравнение с мобильной 112 Operator](docs/112_MOBILE_COMPARISON.md).

## Запуск

Node.js 20+, пакеты для самой игры не нужны:

```sh
npm test
npm start
```

Открыть http://localhost:4173 → «Новая игра» → проверить службы → «Начать смену». Обращение открывается на паузе. Во вкладке «Разговор» уточните обстоятельства и примите решение; во вкладке «Работы» сравните подходящие экипажи и назначьте службы. Затем продолжите время. Смена 08:00–16:00; одна реальная секунда соответствует игровой минуте, доступны 1×/2×/4×.

Бригады можно выбирать также на карте или в нижней панели, затем нажимать на аварию. Ждущую другие службы бригаду можно отозвать. В меню, при сворачивании и после повторного запуска время остановлено. Игра полностью локальная, без аккаунта и сервера.

## Сохранения

Новые компании используют схему v7. Незавершённые этапы, маршруты, назначения, решения, отключения и состояние домов сохраняются между запусками и сменами. Сохранения v4–v6 по-прежнему читаются и продолжаются по прежним правилам. При замене такой компании новой сохраняется отдельный исходный архив, доступный в настройках для экспорта; переходящие работы не переосмысливаются автоматически.

Самая ранняя компания хранится отдельно и доступна в настройках либо через `?legacy=1`. Параметр `?classic=1` нужен разработчикам для регрессионной проверки создания v6-компании. Основной запуск создаёт v7.

Экспортируйте компанию перед очисткой данных или переустановкой. Автосохранение и резервная копия находятся в данных приложения; удаление приложения может удалить их.

## Android

```sh
gradle -p android assembleDebug assembleRelease bundleRelease lintDebug lintRelease
```

GitHub Actions собирает устанавливаемый debug APK и неподписанные магазинные APK/AAB. Артефакт: `upravdom-0.8.2-gameplay.2-debug-apk`. Импорт и экспорт используют системный выбор документа; сетевые разрешения, реклама и платежи отсутствуют. Инструкция по подписи: [docs/RELEASE.md](docs/RELEASE.md). Публикация в магазине сейчас не выполняется.

## Проверка

```sh
npm install --no-save --package-lock=false playwright@1.62.1
npx playwright install chromium
npm run test:dispatch
npm run test:ui
npm run test:balance
npm run test:performance
```

`test:dispatch` проходит первую смену через реальные элементы интерфейса, проверяет продолжение компании и сохранение связанной аварии на 344/412/960 пикселях. `test:ui` также проверяет совместимость предыдущих компаний. Отчёты и снимки находятся в `test-results/`. `test:balance` проверяет обе модели кампании, включая две стратегии новой кампании; это боты, а не оценка интереса или сложности для человека. Можно указать `CHROMIUM_PATH` для установленного системного Chromium.

## Основные модули

- `web/campaign-engine.js` — общая компания, управление ресурсами и транзакционное сохранение v4–v7.
- `web/shift-operations.js` — этапы аварий, несколько служб, зависимости, последствия, дома и рост компании.
- `web/operations-content.js` — авторские обращения, решения, оснащение, погода и планы смен.
- `web/campaign-map.js` — общий художественный рендерер для старой и новой кампании; `web/operations-ui.js`, `web/operations-ui.css` расширяют существующие компоненты для совместных аварий и домов.
- `web/campaign-app.js` — жизненный цикл приложения, управление временем, ввод, диалоги и импорт/экспорт.
- `web/campaign-city.js`, `web/city-layout.js`, `web/city-geography.js` — адреса и координаты города; исходная художественная карта используется в обеих кампаниях.
- `android/` — офлайн WebView и системная работа с документами.

В игре используются оригинальные материалы проекта. Графика, звук, тексты и код 112 Operator не копируются. Открытая лицензия не назначена; её выбирает владелец перед распространением.
