# Управдом · диспетчерская ЖКХ

Версия **0.6.0-alpha**. Новая кампания: **20 районов, в каждом 999 адресов и 999 однократных заданий**. Все 999 нужно выполнить, чтобы добавить следующий район на общую карту. Всего 19 980 заданий.

В 0.6 карта пересобрана из десяти наборов и 32 сухопутных фрагментов: жилые зоны, высотный центр, промышленные участки и непрерывные реки с мостами. Будущие районы видны затемнёнными, открытие требует всех 999 заданий. Сохранения 0.4/0.5 переносятся автоматически с архивом исходной версии. Подробности: [docs/GEOGRAPHY_0_6.md](docs/GEOGRAPHY_0_6.md).

В 0.5 устранено дублирование улиц на стыках тайлов, добавлены анимации девяти рабочих механизмов, движение и сигналы всех машин, обычный трафик и рабочие сцены. Топливо, обслуживание, сроки и оплата переработаны; полная кампания проверена автосимуляцией с тремя и шестью бригадами. Обновление сохранений 0.4 выполняется автоматически, исходная копия сохраняется отдельно.

Изменения, ограничения и проверенные результаты: [docs/MOTION_BALANCE_0_5.md](docs/MOTION_BALANCE_0_5.md).

## Запуск и игра

Node.js 20+, пакеты для самой игры не нужны:

```sh
npm test
npm start
```

Открыть http://localhost:4173 → «Начать игру» → подготовить бригады → «Начать смену». Входящие заявки выбираются на карте или в списке. Уточните обстоятельства и назначьте подходящую технику с сотрудниками; маршрут, осмотр и ремонт выполняются по игровому времени. Смена 08:00–16:00; одна секунда = одна минута, доступны пауза и 1×/2×/4×. Выполненные задания не повторяются, незавершённые сохраняются между сменами.

Главное меню содержит только новую игру, продолжение и настройки. Подготовка: бригады, техника, персонал и склад. На карте — карточки машин, маркеры заявок, маршруты, каталог с поиском всех 999 адресов и общая схема 20 районов. Игра полностью локальная, без аккаунта и сервера.

Старые компании сохранены отдельно: «Настройки → Открыть прежнюю компанию» либо http://localhost:4173/?legacy=1. Новая кампания не перезаписывает прежнее сохранение и не переносит автоматически старую экономику. При наличии только старой компании «Продолжить» открывает её.

Правила, архитектура, проверенные сценарии и известные ограничения: [docs/CAMPAIGN_0_4.md](docs/CAMPAIGN_0_4.md). Это альфа: адресные входы, художественные детали и баланс живой игры требуют приёмки; актуальные проверки сборки и Android доступны в CI. Задания — уникальные в пределах района комбинации подготовленных сюжетов и параметров, не 999 разных механик.

## Android

JDK 17, Gradle 8.9, Android SDK 35, AGP 8.7.3. Минимум Android 8.0 / API 26 с обновлённым WebView/Chromium 100+. Проект `android/` открывается в Android Studio:

```sh
gradle -p android assembleDebug assembleRelease lintDebug lintRelease
```

Gradle wrapper не включён; CI устанавливает Gradle 8.9. GitHub Actions собирает устанавливаемый **debug APK**, неподписанный release APK и снимки браузерных проверок. Debug-пакет находится в Actions → Test and build Android → Artifacts → `upravdom-0.6.0-alpha-debug-apk`.

Для магазинного релиза нужны production-подпись, требования выбранного магазина и проверка на устройстве. Ключи не должны попадать в репозиторий. Статус и ручные проверки: `docs/RELEASE_CHECKLIST.md`.

Импорт и экспорт используют системный выбор документа. Игра не запрашивает доступ ко всему хранилищу, не использует сервер, аккаунт, сетевые разрешения, рекламу или платежи. Очистка данных приложения удаляет локальный прогресс и резервную копию; сохраните экспорт перед очисткой.

## Браузерная проверка

Только для разработки:

```sh
npm install --no-save --package-lock=false playwright@1.62.1
npx playwright install chromium
npm run test:ui
```

Проверки сами запускают сервер. Сборка карты: `npm run test:geography`, снимки — `test-results/geography/`. Новая кампания: `npm run test:campaign`, снимки — `test-results/campaign/`. Анимации и стыки: `npm run test:motion`, снимки — `test-results/motion/`. Экономика полной кампании: `npm run test:balance`. Прежняя компания: `tools/playability.cjs` и `tools/ui-smoke.cjs`, снимки — `test-results/screenshots/`. Для системного Chromium можно задать `CHROMIUM_PATH`.

## Структура

- `web/campaign-engine.js` — новая кампания, выезды, переходы и сохранения v6 с миграцией v4/v5.
- `web/campaign-city.js`, `web/content-missions.js` — 20 районов, адресные входы и подготовленные задания.
- `web/city-geography.js`, `web/city-layout.js`, `web/campaign-terrain.js` — зоны, реки и сборка кварталов.
- `web/campaign-map.js` — карта города, улицы и машины.
- `web/campaign-app.js`, `web/campaign.css` — меню, подготовка и диспетчерская.
- Следующие файлы обслуживают сохранённый прежний режим:

- `web/engine.js` — детерминированная симуляция и проверка сохранений.
- `web/roads.js` — дорожный граф, маршруты и время поездки.
- `web/app.js`, `web/style.css` — интерфейс, ввод и управление временем.
- `web/map.js`, `web/assets/` — карта, атлас автомобилей и изображения районов.
- `web/content.js`, `web/management.js` — каталоги и интерфейс управления компанией.
- `web/legacy-engine.js` — чтение старых сохранений для миграции.
- `web/storage.js` — резервная копия, загрузка и настройки.
- `android/` — офлайн WebView и системный импорт/экспорт.
- `tests/`, `tools/ui-smoke.cjs`, `tools/playability.cjs` — автоматические проверки.

## Права

Векторные элементы и карта подготовлены для проекта; исходный визуальный референс предоставлен пользователем. Открытая лицензия не назначена: перед распространением владелец выбирает лицензию. Чужие игровые материалы не используются.
