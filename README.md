# Управдом · УК «Уют»

Офлайн-симулятор управляющей компании для Android. Версия **0.3.0-alpha**, альфа серьёзной переработки игрового цикла и объёмной карты.

Вы начинаете с **3 000 000 ₽, трёх домов, трёх бригад, трёх автомобилей и шести специалистов**. Принимайте обращения, уточняйте обстоятельства, распределяйте выезды и следите за состоянием района.

## Запуск

Node.js 20+, установка пакетов для игры не нужна:

```sh
npm test
npm start
```

Открыть http://localhost:4173. Нажать «Начать смену» на карте. Игровая минута занимает секунду; смена 08:00–16:00. Есть пауза и скорости 1×/2×/4×. Открытые карточки и сворачивание останавливают время.

## Возможности

- Объёмный город: отдельные здания, дороги, крыши, дворы, деревья, автомобили, адреса и маркеры заявок.
- Пять разделов: карта, заявки, бригады, финансы, гараж.
- 20 сценариев обращений, сроки, диагностика, ремонт, подрядчики и последствия просрочки.
- Найм, индивидуальное обучение и зарплаты сотрудников; покупка автомобилей; формирование бригад из людей и техники.
- Склад комплектов, обычные и срочные поставки, грузоподъёмность машин и резервирование материалов.
- Развитие по трём районам, новые договоры, доверие жителей, удержания, потеря договора и цели кампании.
- Договорные доходы, зарплаты, журнал, профилактика; отчёт учитывает подготовку к смене.
- Основное и резервное сохранение с восстановлением; миграция старого формата; импорт/экспорт JSON.
- Звуки новых обращений, отключение анимации и адресных подписей.

Карта — локальная 3D-сцена с отдельными зданиями, дворами, деревьями и автомобилями. Можно поворачивать камеру и менять наклон. На устройствах без WebGL 2 используется упрощённая карта. В городе три района и 12 возможных договоров; стартовые договоры — три. Найм, автомобили, сборка бригад и закупки доступны в соответствующих разделах. Выплаты зависят от обслуживания; договор можно потерять. Подробности и ограничения: `docs/REWORK_0_3.md`.

## Android

JDK 17, Gradle 8.9, Android SDK 35, AGP 8.7.3. Минимум Android 8.0 / API 26 с обновлённым WebView/Chromium 100+. Проект `android/` открывается в Android Studio:

```sh
gradle -p android assembleDebug assembleRelease lintDebug lintRelease
```

Gradle wrapper не включён; CI устанавливает Gradle 8.9. GitHub Actions собирает устанавливаемый **debug APK**, неподписанный release APK и снимки браузерных проверок. Debug-пакет находится в Actions → Test and build Android → Artifacts → `upravdom-0.3.0-alpha-debug-apk`.

Для магазинного релиза нужны production-подпись, требования выбранного магазина и проверка на устройстве. Ключи не должны попадать в репозиторий. Статус и ручные проверки: `docs/RELEASE_CHECKLIST.md`.

Импорт и экспорт используют системный выбор документа. Игра не запрашивает доступ ко всему хранилищу, не использует сервер, аккаунт, сетевые разрешения, рекламу или платежи. Очистка данных приложения удаляет локальный прогресс и резервную копию; сохраните экспорт перед очисткой.

## Браузерная проверка

Только для разработки:

```sh
npm install --no-save --package-lock=false playwright@1.62.1
npx playwright install chromium
npm run test:ui
```

Проверка сама запускает сервер, проверяет все разделы, полный день, сохранения и экспорт/импорт. Скриншоты — `test-results/screenshots/`. Для системного Chromium можно задать `CHROMIUM_PATH`.

## Структура

- `web/engine.js` — детерминированная симуляция и проверка сохранений.
- `web/roads.js` — дорожный граф, маршруты и время поездки.
- `web/app.js`, `web/style.css` — интерфейс, ввод и управление временем.
- `web/map.js`, `web/assets/` — фон и динамические элементы карты.
- `web/storage.js` — резервная копия, загрузка и настройки.
- `android/` — офлайн WebView и системный импорт/экспорт.
- `tests/`, `tools/ui-smoke.cjs` — автоматические проверки.

## Права

Векторные элементы и карта подготовлены для проекта; исходный визуальный референс предоставлен пользователем. Открытая лицензия не назначена: перед распространением владелец выбирает лицензию. Чужие игровые материалы не используются.
