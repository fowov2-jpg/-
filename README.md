# УПРАВДОМ · УК «Уют»

Офлайн диспетчерский и экономический симулятор ЖКХ для Android. Версия **0.1.0: играбельный прототип первой карты**, не коммерческий релиз.

Начальные условия: **3 000 000 ₽ · 3 дома · 3 бригады · 3 автомобиля · 6 специалистов**.

## Быстрый запуск

Требуется Node.js 20+. Пакеты для игры устанавливать не нужно.

```sh
npm test
npm start
```

Открыть http://localhost:4173. В «Карте» нажать «Начать смену», открыть заявку, уточнить обстоятельства и отправить бригаду. Четыре раздела: Карта, Заявки, Службы, Финансы. Одна секунда = одна игровая минута; смена 08:00–16:00. Есть пауза, скорости 1×/2×/4×. Диалоги автоматически останавливают ход времени.

## Android

Проект `android/` открывается в Android Studio. Среда: JDK 17, Gradle 8.9, Android SDK 35, AGP 8.7.3. Минимальная версия Android — 8.0 (API 26). Игра использует локальный WebView с Canvas 2D и WebViewAssetLoader, не требует сервера, сетевого разрешения или аккаунта.

```sh
gradle -p android assembleDebug lintDebug
```

Gradle wrapper намеренно не включён: используйте установленный Gradle 8.9 или среду CI. GitHub Actions `.github/workflows/build.yml` устанавливает указанную версию, запускает тесты и собирает debug APK. Результат: Actions → Test and build Android → Artifacts → upravdom-debug-apk.

Для Play Store нужна отдельная release-подпись, актуализация target SDK под требования публикации, тестирование на устройствах и release-сборка. Ключи подписи в репозиторий не добавлять.

## Что реализовано

- Процедурная изометрическая карта: здания, деревья, дороги, машины, маршруты; pan/pinch/zoom.
- 20 типов обращений и уточняющие реплики, приоритеты, сроки и последствия просрочки.
- Три специализации; назначение → дорога → диагностика → ремонт → освобождение.
- Резерв материалов при назначении, подрядчики, топливо, состояние машин, усталость, обучение и оснащение.
- Договорные доходы, зарплаты, постоянные расходы, журнал операций, профилактика.
- Подготовка, смена, отчёт, следующий день; перенос незавершённых работ.
- Сезонные веса заявок, износ домов, воспроизводимый генератор событий.
- Версионированное локальное сохранение; при сворачивании время останавливается.
- Собственные векторные иконки и Android launcher icon.

## Границы версии

Карта нарисована кодом и стилизована; она не повторяет детализацию 3D-рендера из референса. Машины и персонажи пока представлены условными векторными элементами. Нет озвучки, музыки, отдельного склада с номенклатурой, индивидуальных карточек шести сотрудников, найма, тендеров, конкурентов, кредитов, лизинга, тяжёлой техники и нескольких районов. Развитие этих систем описано в `docs/GAME_DESIGN.md`. Иконки интерфейса находятся в `web/icons.js`, отдельные SVG — в `assets/icons/`.

Проверки и известные ограничения сборки: `docs/VERIFICATION.md`.

## Структура

- `web/engine.js` — детерминированная модель без DOM и зависимостей.
- `web/app.js` — интерфейс, сохранение, ввод и управление временем.
- `web/map.js` — Canvas-рендер и маршруты по дорожной сетке.
- `web/icons.js`, `web/style.css` — графические элементы и дизайн-система.
- `android/` — нативная оболочка, ограниченная локальными ресурсами.
- `tests/` — проверки экономики, назначений, сохранений и смен.
- `docs/` — дизайн, баланс, архитектура, план развития, проверка.

Сохранения остаются на устройстве. Очистка данных приложения удаляет прогресс. Прототип не использует аналитику, рекламу, платежи или внешние сервисы.

## Права

Новые код и векторная графика подготовлены для этого проекта. Открытая лицензия не назначена: перед публичным распространением владелец выбирает лицензию. Пользовательский визуальный референс не включён в игровые ресурсы. 112 Operator упоминается только как жанровый ориентир; чужие игровые материалы не используются.

## Экспериментальная карта 0.2 — ветка feature/reference-map-ui-v02

В активной разработке интерфейс по референсному изображению: пять вкладок (включая Гараж), компактный статус игры, аварийная карточка, анимированные цветные маршруты, погодные эффекты и более детальная процедурная изометрическая карта. Сохранения и экономическая логика версии 0.1 остаются совместимыми.

Проверка: `npm test` запускает игровые и графические unit-тесты. Дополнительный workflow **Mobile UI smoke** использует Chromium и проверяет основные действия игры, все пять вкладок и размеры экранов 360, 412, 1200 px; скриншоты доступны в артефакте **mobile-map-ui-screenshots** этого workflow. Для ручной проверки локально — `npm start` и браузер по адресу http://localhost:4173.

**Ограничение:** карта остаётся векторным 2.5D-рендером. Она интерактивная и не является фотографией/готовым 3D-рендером из визуального референса. Для достижения качества исходного изображения нужны художественные тайлы, модели, текстуры и профилирование на устройствах.
